# 菌落触手战 · Colony Tendrils

按 2011 年 Lumarama 的 Flash 游戏《Tentacle Wars: The Purple Menace》的规则与 20 个原版关卡，用 HTML5 Canvas 重新实现的微生物触手策略游戏。单个 `index.html`，无依赖、无构建步骤。

## 玩法

- **伸出**：从绿色微生物拖到目标上松开，伸出触手。每节触手消耗 1 点能量。
- **输送**：触手接上后持续输送能量——削弱敌人（归零即占领）、灌入中立、或支援自己人。
- **切断**：在空白处划过自己的触手。切口到你这边的部分收回，到目标那边的部分一口气灌进目标。
- **中立**：灌入其能量的 1/3 即可占领，占领后保留原有能量。
- **进化**：孢子(1) → 胚胎(2) → 脉冲星-A(2) → 脉冲星-B(2) → 蚁(3) → 掠食者(3)（括号为触手上限），等级越高攻击越快、自身增长越慢。
- 占领场上所有非中立的外来微生物即可过关。快捷键：P 暂停、R 重来、Esc 返回。

## 与原版一致的部分

全部数值直接取自原版代码：20 帧/秒的逻辑节拍、进化阈值与周期、触手节长 11px、切断/回收/中点交锋规则、墙壁判定、细胞互斥推挤、红/黑/紫三种 AI 的进攻、支援与撤退逻辑、首次过关积分 `max(5, 100 - 用时)`。画面与音效为程序重新绘制与合成，未使用原版素材。

## 部署到 Cloudflare Pages

1. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接到 Git，选择本仓库。
2. 框架预设：无；构建命令：留空；构建输出目录：`/`。
3. 保存并部署。

进度（已解锁区域、积分、最快用时）保存在浏览器 localStorage。
