# 菌落触手战 · Colony Tendrils

用 HTML5 Canvas 制作的微生物触手策略游戏：经典战役完整复刻一款老 Flash 游戏的规则与 20 个关卡，并在此基础上加入了新的玩法和玩家关卡大厅。前端是纯静态网页，无依赖、无构建步骤。

## 模式

| 模式 | 内容 |
| --- | --- |
| 经典战役 | 原版 20 个区域，规则与关卡逐帧复刻 |
| 第二章 · 异变 | 10 个新关卡，引入增幅器、甲壳、毒囊、汲取者、游走微生物和移动之墙 |
| 无尽进化 | 随机生成的培养皿，每过一层三选一「突变」；第 5 层起敌人也会突变 |
| 关卡编辑器 | 摆放微生物和墙、设置游走/移动，一键试玩，通关后上传到大厅 |
| 关卡大厅 | 把自己设计的关卡上传给所有人玩；按最新/最热/好评浏览、搜索、点赞 |

## 基本玩法

- **伸出**：从绿色微生物拖到目标上松开，伸出触手。每节触手消耗 1 点能量。
- **输送**：触手接上后持续输送能量——削弱敌人（归零即占领）、灌入中立、或支援自己人。
- **切断**：在空白处划过自己的触手。切口到你这边的部分收回，到目标那边的部分一口气灌进目标。
- **中立**：灌入其能量的 1/3 即可占领，占领后保留原有能量。
- **进化**：孢子(1) → 胚胎(2) → 脉冲星-A(2) → 脉冲星-B(2) → 蚁(3) → 掠食者(3)（括号为触手上限）。
- 占领场上所有非中立的外来微生物即可过关。快捷键：P 暂停、R 重来、Esc 返回。

## 新微生物与机关

| 名称 | 效果 |
| --- | --- |
| 增幅器 | 不会自行增长，发出的能量包威力 ×2 |
| 甲壳 | 受到的敌方伤害减半 |
| 毒囊 | 每秒溶解一节接在它身上的敌方触手 |
| 汲取者 | 能量包每命中敌人两次，自己回复 1 点 |
| 游走 | 沿虚线轨迹来回移动，触手随之拉长（付能量）或缩短（返还） |
| 移动之墙 | 来回移动，会切断它扫过的任何触手 |

## 关卡大厅

- 在编辑器里**试玩并打赢一次**后，「上传」按钮才会放行，保证大厅里的关卡都能通关。
- 大厅可按「最新 / 最热 / 好评」浏览，支持按关卡名或作者搜索；每个关卡记录挑战次数、胜率和点赞数。
- 每关有自己的链接：`https://你的域名/#L.关卡ID`，打开就能直接挑战。
- 「我的上传」里可以删除自己上传的关卡（按浏览器识别上传者）。
- 同一关卡布局只会收录一次；同一 IP 每小时最多上传 10 关；被 5 个不同玩家举报的关卡会自动从列表隐藏。

## 与原版一致的部分

经典战役的全部数值直接取自原版代码：20 帧/秒的逻辑节拍、进化阈值与周期、触手节长 11px、切断/回收/中点交锋规则、墙壁判定、细胞互斥推挤、红/黑/紫三种 AI 的进攻、支援与撤退逻辑、首次过关积分 `max(5, 100 - 用时)`。新机制全部是可选的修饰层，不影响原版关卡（重构后与第一版逐帧比对一致）。画面与音效为程序重新绘制与合成，未使用原版素材。

## 部署到 Cloudflare Pages

1. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接到 Git，选择本仓库。
2. 框架预设：无；构建命令：留空；构建输出目录：`/`。
3. 保存并部署。之后每次推送到 `main` 都会自动更新。

### 开启关卡大厅（一次性，约 2 分钟）

大厅的后端是仓库里的 `functions/api/[[route]].js`（Pages Functions，会随站点自动部署），数据存在 Cloudflare D1 数据库里。数据表会在第一次访问时自动创建，不需要手动建表。

1. 控制台 → **Storage & Databases → D1** → **Create**，随便起个名字（比如 `colony-tendrils`）。
2. 打开你的 Pages 项目 → **Settings → Bindings → Add → D1 database**：
   - Variable name 填 **`DB`**（必须是这个名字）
   - D1 database 选刚才建的数据库
3. （可选）**Settings → Variables and Secrets → Add**，名字填 `ADMIN_KEY`，值填一串只有你知道的密码，勾选 **Encrypt** 后保存。之后在自己的网址后面加 `#admin` 打开，填入这个密码，大厅里每个关卡都会出现删除按钮。
4. **重新部署一次**（Deployments 里对最新部署点 Retry deployment，或者随便推送一个提交），绑定才会生效。
5. 打开 `https://你的域名/api/stats`，看到 `{"count":0}` 就说明大厅已经接通。

没绑定数据库时游戏其他部分照常可玩，大厅页会提示「大厅暂时用不了」。

### 本地调试

需要 Node 22 以上：`node tools/dev-server.mjs 8788`，然后打开 http://localhost:8788 。这个脚本模拟 Pages 的静态托管和 Functions，用 Node 自带的 SQLite 模拟 D1（默认存在内存里，第三个参数可以指定数据库文件）。

进度（已解锁关卡、积分、最快用时、无尽纪录、编辑器草稿、我的上传）保存在浏览器 localStorage。
